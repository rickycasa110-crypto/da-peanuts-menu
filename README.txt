DA PEANUTS — MENU DIGITALE
============================

Questa è la prima versione del menù digitale.

STRUTTURA:
- index.html = pagina del menù
- style.css = grafica
- menu-data.js = prodotti, descrizioni e prezzi
- script.js = visualizzazione automatica
- assets/logo-da-peanuts.jpg = logo

COME INSERIRE I PRODOTTI:
Apri menu-data.js e sostituisci i commenti con righe come:

{ nome: "Cappuccino", descrizione: "Latte e caffè espresso", prezzo: "2,00 €" },

Non serve modificare index.html.

PUBBLICAZIONE:
Il sito può essere pubblicato gratuitamente con GitHub Pages.
Quando sarà online avremo un indirizzo web stabile e potremo generare il QR code definitivo.
